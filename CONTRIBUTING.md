# Contributing to Security-Lab-Interactive

🎉 Thank you for considering contributing to Security-Lab-Interactive!

## How to Contribute

### 1. Fork the Repository
- Click the "Fork" button at the top right of the repository
- Clone your forked repository to your local machine

```bash
git clone https://github.com/YOUR_USERNAME/Security-Lab-Interactive.git
cd Security-Lab-Interactive
```

### 2. Create a Branch
Create a new branch for your feature or bug fix:

```bash
git checkout -b feature/your-feature-name
```

### 3. Make Your Changes
- Follow Python coding standards (PEP 8)
- Add comments and docstrings to your code
- Test your changes thoroughly

### 4. Commit Your Changes
```bash
git add .
git commit -m "Add brief description of changes"
```

### 5. Push to Your Fork
```bash
git push origin feature/your-feature-name
```

### 6. Create a Pull Request
- Go to the original repository
- Click "New Pull Request"
- Select your branch and provide a clear description

## Guidelines

✅ **DO:**
- Write clear, descriptive commit messages
- Follow Python PEP 8 style guide
- Add docstrings to functions
- Test your code before submitting
- Keep pull requests focused and manageable

❌ **DON'T:**
- Submit unrelated changes in one PR
- Ignore existing code style
- Remove test files or documentation
- Use copyrighted material without permission

## Contribution Ideas

- 📝 Improve documentation
- 🐛 Report and fix bugs
- ✨ Add new labs and challenges
- 🔐 Enhance security concepts explanations
- 🎯 Create interactive CTF walkthroughs
- 📚 Add references and resources

## Code of Conduct

- Be respectful and constructive
- Help others learn and grow
- Focus on cybersecurity education
- Practice ethical hacking principles

## Questions?

If you have questions, please open an Issue on GitHub.

Happy contributing! 🚀
